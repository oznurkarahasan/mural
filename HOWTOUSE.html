Mural Wall Plotter

A wall-hanging drawing robot controlled via a web browser. Mural hangs from two nails on a wall and draws SVG images using a pen and two stepper motors that control belt lengths.

4 First-Time Setup: Flashing the Firmware

Mural uses PlatformIO for building and flashing.

Requirements

  • VS Code with the PlatformIO extension, or PlatformIO CLI
  • USB cable connected to the ESP32

Steps

  1. Open the project folder in VS Code.
  2. Connect the ESP32 via USB.
  3. Flash the firmware: 
    pio run --target upload
  4. Flash the web interface (LittleFS filesystem): 
    pio run --target uploadfs
⚠️ The uploadfs step uploads web files from data/www/ to the ESP32's flash. You must do this at least once, or the web interface will not load.
  1. Open the Serial Monitor at baud rate 9600 to watch the boot log.

5 Connecting to Mural's Wi-Fi

On first boot (or if Wi-Fi credentials are lost):

  1. Mural creates a Wi-Fi access point called Mural.
  2. Connect to it from your phone or computer.
  3. A captive portal opens automatically (or navigate to 192.168.4.1).
  4. Select your home Wi-Fi network and enter the password.
  5. Click Save. Mural will restart and connect to your Wi-Fi.

Once connected, the OLED display shows:

http://192.168.x.x
      or
http://mural.local
💡 http://mural.local works on most modern devices without needing to look up the IP address. Android devices may require the IP instead.

6 Using the Web Interface — Step by Step

The web interface guides you through a series of phases in order. Each phase must be completed before moving to the next.

Phase 1 — Set Distance Between Hangers

What you see: A number input field asking for the distance between the two nails/hangers.

What to do:

  1. Measure the horizontal distance between the two nails on the wall, in millimeters.
  2. Enter the value (e.g., 1000 for 1 meter).
  3. Click Set distance.
⚠️ This value is critical for drawing accuracy. Measure carefully.

Phase 2 — Select SVG Image

What you see: A file picker and a preview area with pan/zoom controls.

What to do:

  1. Click the file input and select an SVG file from your computer.
  2. Use the D-pad to pan and zoom buttons to resize.
  3. Click Preview drawing to process the SVG.
ℹ️ Use black and white line art SVGs for best results. Complex gradients and raster images are not supported.

Phase 3 — Choose Render Type

OptionBest For
Path TracingMost drawings; follows SVG paths directly
Vector → Raster → VectorPreserves stroke width and thickness

Phase 4 — Drawing Preview & Settings

SettingDescription
Infill DensityAdds hatching/fill inside shapes (0 = outlines only)
DespeckleRemoves small noise artifacts (higher = removes more tiny features)
Flatten PathsSimplifies curves into straight line segments

Adjust settings, then click Accept to upload to the ESP32.

Phase 5 — Retract Belts

  1. Place the belt loops on the homing screws of the gondola.
  2. Toggle Left motor ON to retract. Turn it OFF as soon as it stalls.
  3. Repeat for Right motor.
  4. Click Belts are retracted.
🔥 Warning: Do not leave motors stalling for long — this generates heat and can damage drivers.

Phase 6 — Extend Belts to Home Position

  1. Make sure the gondola is free to move and belts are unobstructed.
  2. Click Extend to home position and wait for the spinner to disappear.
ℹ️ If motors skip steps here, drawing accuracy will be affected. Re-hang Mural and ensure belts run freely.

Phase 7 — Pen Calibration

  1. Insert the pen so it's close to, but not touching the wall. Secure with the bolt.
  2. Use the slider or +/− buttons to push the pen toward the wall.
  3. When the pen tip just touches the wall, click Pen is touching the wall.

Phase 8 — Begin Drawing

Click Begin Drawing to start. The web server shuts down during drawing; the OLED shows progress (0%–100%). The ESP32 restarts automatically when done.

Click Reset to restart from Phase 1 without drawing.

7 Preparing an SVG for Drawing

  • Use line art only — outlines, not filled shapes with gradients.
  • Black and white only — color information is ignored.
  • Keep it simple — fewer, cleaner paths = better results and faster drawing.
  • The SVG is scaled to fit automatically:
    • Drawing area width = 60% of pin distance (e.g., 600 mm for 1000 mm pins)
    • 20% margin on each side, 20% margin at the top
    • Height scaled proportionally

Recommended Tools

  • Inkscape — free, open-source vector editor
  • Adobe Illustrator
  • SVGomg — free online SVG optimizer

10 Calibration: E-Steps

E-steps calibration ensures the motor moves the correct physical distance per step. Run this if drawings come out distorted or scaled incorrectly.

  1. Open the Tools Modal (gear icon).
  2. Mark a reference point on the belt.
  3. Click Extend 1000mm.
  4. Measure the actual distance the belt moved.
  5. Calculate the correction: 
    new_steps_per_rotation = current_steps_per_rotation × (1000 / measured_mm)
  6. Update stepsPerRotation in src/movement.h (currently 200 * 8 = 1600).
  7. Re-flash the firmware.

11 Tips & Troubleshooting

Mural is not reachable at http://mural.local

  • Try the IP address shown on the OLED display instead.
  • mDNS may not work on some Android devices — use the IP address directly.

The drawing is skewed or inaccurate

  • Re-measure the pin distance and re-enter it exactly.
  • Check that neither belt skipped steps during "Extend to home".
  • Run E-steps calibration (Section 10).

Motors stall immediately when retracting

  • The belts may already be fully retracted — toggle the motor off and click "Belts are retracted".

OLED shows "SSD1306 allocation failed"

  • Check I²C wiring: SDA → GPIO 21, SCL → GPIO 22.
  • Verify the OLED's I²C address is 0x3C.

Web interface does not load (blank page or 404)

  • The LittleFS filesystem was not uploaded. Run:
pio run --target uploadfs

Drawing starts but pen never touches the wall

  • Pen calibration was set incorrectly. Reset and redo Phase 7.

ESP32 restarts after drawing is done

  • This is normal. The ESP32 restarts automatically after drawing completes so the web interface becomes accessible again.

Want to connect to a different Wi-Fi network

  • Credentials are stored by WiFiManager. To reset them, erase the ESP32 flash and re-upload.
